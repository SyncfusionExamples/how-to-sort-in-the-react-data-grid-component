# How to Sort in the React Data Grid Component

A quick-start project that demonstrates how to perform sorting in the Syncfusion React Data Grid component. This project also includes examples of initial sorting, multicolumn sorting, and implementing custom sorting.
 
Refer to the following documentation to learn about the React Data Grid component: 
https://ej2.syncfusion.com/react/documentation/grid/sorting
 
Check out this online example of the React Data Grid component:
https://ej2.syncfusion.com/react/demos/#/tailwind3/grid/sorting
 
## Project prerequisites
Make sure that you have the compatible versions of [Visual Studio Code](https://code.visualstudio.com/download ) and [NodeJS](https://nodejs.org/en/download) or later version in your machine before starting to work on this project.
 
## How to run this application
To run this application, you need to first clone the `how-to-sort-in-the-react-data-grid-component` repository and then open it in Visual Studio Code. Now, simply Build and run your project using the npm run dev command to view the output.
